# dsRNA-brick

A unified workflow for dsRNA-brick nanostructure design, from KL-pool selection to lattice construction and NUPACK sequence optimization.

## What This Repository Contains

This repository has three main modules:

1. `Orthogonal_sequence_selection/`
   - Builds an orthogonal KL sequence pool by graph-based conflict filtering.
   - Main scripts generate candidate pools, build conflict graphs, and select independent sets.
   - Details: [`Orthogonal_sequence_selection/README.md`](Orthogonal_sequence_selection/README.md)

2. `build_dsRNA_bricks_2D/`
   - GUI for 2D lattice design (`X`, `Y`) with synchronized 3D view + XY map selection.
   - One-click sequence export + NUPACK run.
   - Details: [`build_dsRNA_bricks_2D/README.md`](build_dsRNA_bricks_2D/README.md)

3. `build_dsRNA_bricks_3D/`
   - GUI for 3D lattice design (`X`, `Y`, `Z`) with synchronized 3D view + layered XY maps.
   - One-click sequence export + NUPACK run.
   - Details: [`build_dsRNA_bricks_3D/README.md`](build_dsRNA_bricks_3D/README.md)

## End-to-End Workflow

1. Build/select KL pool
   - Use `Orthogonal_sequence_selection` to generate an orthogonal sequence set.
   - Typical output is a KL-pair pool file (tab-separated RNA pairs).

2. Build lattice in GUI (2D or 3D)
   - Load KL pool file.
   - Set lattice dimensions and prefix.
   - Click `Build lattice`.

3. Select tiles for sequence generation
   - Selection is synchronized between 3D and 2D map views.
   - Selection validity rules:
     - No flexible tiles: every selected tile must have at least 2 interactions with other selected tiles.
     - Single connected group only: no multiple disconnected closed groups.

4. Generate sequence
   - Click `Generate sequence`.
   - Pipeline exports tile structure + 2D map, then runs NUPACK.

## NUPACK Design Principles

The integrated sequence-design step uses the following settings:

- RNA model with `some-nupack3` ensemble.
- Temperature: `37°C`.
- Sodium concentration: `1.0 M`.
- Soft pattern-avoidance (weight `1.0`) for:
  - `A4`, `C4`, `G4`, `U4`, `K6`, `M6`, `R6`, `S6`, `W6`, `Y6`
- Stop condition for optimization: `f_stop = 0.02`.
- Per-tile design runs `3` trials and keeps the best result.

## Common Output Files

For a given prefix `<prefix>`, GUI pipelines generate:

- `<prefix>_tile_structure.txt`
  - Tile scaffold sequence + target secondary structure.
- `<prefix>_2D_map.svg`
  - 2D map with tile annotations.
- `<prefix>_sequence.txt`
  - Final NUPACK-designed sequences.

## Quick Start

### Environment

Recommended Python stack:

- Python `3.12`
- `PySide6==6.9.*`
- `numpy`
- `pyvista`
- `pyvistaqt`
- `vtk`
- `nupack`

Example:

```bash
conda create -n dsrna python=3.12 -y
conda activate dsrna
pip install "pyside6==6.9.*" numpy pyvista pyvistaqt vtk
```

Install/configure NUPACK using official docs:

- [https://docs.nupack.org/](https://docs.nupack.org/)

### Run 2D GUI

```bash
cd build_dsRNA_bricks_2D
python build_dsRNA_Bricks_2D.py
```

### Run 3D GUI

```bash
cd build_dsRNA_bricks_3D
python build_dsRNA_Bricks_3D.py
```
