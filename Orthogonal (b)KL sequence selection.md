<code>gen_pattern_sw</code>)</h4><div>For each 9‑nt pattern, it:</div><ul><li><div>Picks positions of the 4 S’s (indices Sa, Sb, Sc, Sd) and fills the rest with W.</div></li><li><div>Rejects patterns that:</div></li><ul><li><div>have <b>4 consecutive S</b> (avoids long GC runs),</div></li><li><div>have a <b>long run of W at the 5′ end</b> (avoids very A/U‑rich 5′ segments, following the original style="--en-nodeId:f6ca15e1-1251-4543-8ac0-b551b05a1a3a;">Assigning A/G/U/C (function <code>assign_seq_for_pattern</code>)</h4><div>For each S/W pattern, it enumerates all <code>2^N</code> assignments:</div><ul><li><div>At each W position: choose <b>A or U</b></div></li><li><div>At each S position: choose <b>G or C</b></div></li></ul><div>For each resulting sequence <code>s</code> (length 9), it applies filters:</div><ol><li><div><b>All four nucleotides must appear at least once</b></div></li><ul><li><div><code>s</code> must contain <b>A, G, U, and C</b> somewhere.</div></li></ul><li><div><b>Hairpin exclusion (for N ≥ 9, so yes for 9‑mers)</b></div></li><ul><li><div>It looks at the would‑be stem formed by the outer 3 pairs:</div></li><ul><li><div>Pairs <code>s[0]–s[-1]</code>, <code>s[1]–s[-2]</code>, <code>s[2]–s[-3]</code>.</div></li></ul><li><div>Two scores:</div></li><ul><li><div><code>score</code> using positions look pairable in either sense (<code>score ≥ 3</code> or <code>score_comp ≥ 3</code>), the sequence is <b>discarded</b> – it’s too hairpin‑like.</div></li></ul><li><div><b>No internal “UUU” or mirrored “AAA”</b></div></li><ul><li><div>For positions <code>i = 2 ... N-3</code> (internal):</div></li><ul><li><div>Reject if there is <code>U U U</code> at <code>s[i:i+3]</code>.</div></li><li><div>Reject if there is <code>A A A</code> at the <b>mirrored</b> positions at the 5′ side.</div></li></ul><li><div>So we avoid long <b>internal U‑tracts and A‑tracts</b>, which are structurally problematic.</div></li></ul></ol><div>Sequences passing these tests are collected into a pool.</div><h4 style="--en-nodeId:2b1f4d8d-4fa5-4664-ab7d-3ed55952badb;">Final refinement filters (function <code>refine_seq</code>)</h4><div>After pooling all candidates from all patterns, <code>refine_seq</code> applies four more rules:</div><ol><li><div><code><b>if6_kmry</b></code><b> – avoid 6‑long degenerate runs</b></div></li><ul><li><div>K = {G, U}</div></li><li><div>M = {A, C}</div></li><li><div>R = {A, G}</div></li><li><div>Y = {C, U}</div></li><li><div>It tracks the longest consecutive run for each group (K, M, R, Y).
If <b>any group has length ≥ 6</b>, the sequence is <b>rejected</b>. → Roughly: no “6 bases in a row that all behave like purines, pyrimidines, etc.”</div></li></ul><li style="--en-isCollapsed:false;"><div><code><b>if_ends_ww</b></code><b> – both ends weak? reject</b></div></li><ul><li><div>If both 5′ and 3′ ends are A/U (in any combination A/U vs A/U) the sequence is rejected.</div></li><li><div>Ensures <b>at least one end has a G or C</b>, which stabilises the designed KL and reduces problematic 3′/5′ fluff.</div></li></ul><li><div><code><b>if_ends_3w</b></code><b> – 3 weak bases at either end</b></div></li><ul><li><div>If positions 0–2 or positions N-3–N-1 are all A/U, reject.</div></li></ul><li><div><code><b>if_ends_pair_u</b></code><b> – more detailed end hairpin checks</b></div></li><ul><li><div>For N ≥ 9, it looks for patterns like:</div></li><ul><li><div>5′ A at the start or 3′ U at the end,</div></li><li><div>short A‑rich segments at 5′ that could strongly pair with 3′,</div></li><li><div>3′ terminal U or UU that could form a little end‑stem with the 5′ side.</div></li></ul><li><div>If these patterns indicate likely terminal pairing, the sequence is rejected.</div></li></ul></ol><hr/><h2 style="--en-nodeId:3f59bba5-7dc6-44db-8384-028ec49cd53f;">Step 2 – <code><b>build_rna_conflict_graphV2.py</b></code></h2><div><b>Goal:</b> from the raw pool, throw away self‑complementary and guide‑complementary sequences, then build a <b>graph of pairwise conflicts</b> based on strong complementarity.</div><h3 style="--en-nodeId:0faf321d-8292-44e6-9eea-a410af00fd50;">How to run it (9‑nt example)</h3><div>Basic usage with defaults:</div><div style="--en-codeblock:true; The script builds an undirected graph:</div><ul><li><div><b>One node per sequence.</b></div></li><li><div>An <b>edge (i, j)</b> means sequences <i>i</i> and <i>j</i> are “too complementary” under the pairs</b>.</div></li></ul><li><div><b>Shorter but GC‑rich</b></div></li><ul><li><div>Longest consecutive run ≥ <b>N–3</b>, and</div></li><li><div><b>≥ 4 GC pairs</b>.</div></li></ul><li><div><b>Bulged pairing (N ≥ 9)</b></div></li><ul><li><div>There exists a <b>single‑bulge alignment</b> of length <b>N–1</b> between the two sequences (one base skipped on one strand) with <b>≥ 3 GC pairs</b>.</div></li></ul></ol><div>For <b>N = 9</b> these thresholds are:</div><ul><li><div>N–1 = <b>8</b>, N–2 = <b>7</b>, N–3 = <b>6</b>.</div></li><li><div>So two 9‑mers conflict if e.g.:</div></li><ul><li><div>They can form ~8 bp with several GC pairs, <b>or</b></div></li><li><div>They have a contiguous 8‑bp run with >1 GC, <b>or</b></div></li><li><div>They have a contiguous 7‑bp run with >2 GC, <b>or</b></div></li><li><div>They have a contiguous 6‑bp run with ≥4 GC, <b>or</b></div></li><li><div>They can form an <b>8‑bp single‑bulged</b> alignment with ≥3 GC.</div></li></ul></ul><div>This is more nuanced than just “no 5‑bp perfect complement”—it balances <b>length of interaction</b> and <b>GC richness</b>, which controls the expected
